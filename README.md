# Kitab Suci Ibrani — Terjemahan Basa Jawa

Terjemahan Kitab Suci Ibrani (Tanakh) saben ayat — setya marang aksara asline.

## Basa Ibrani luwih dhisik

Terjemahan iki ana kanggo nuntun panjenengan marang basa Ibrani —
dudu kanggo ngganteni. Sing diwaca tansah basa Ibrani — konsonan,
vokal, lan tandha-tandhane. Basa Jawa ing sangisore iku jendhela,
dudu gegenti. Ing ngendi loro-lorone beda, basa Ibrani sing bener.

## Asma

Ing saben panggonan tembung papat-aksara iku katulis, kita nulis
**Yahweh** — ora diganti gelar, ora diganti tembung lumrah.
Kita ora nulis **Yehuwah** (wujud campuran), ora nulis **Gusti**
utawa **Pangeran** (gelar — dudu asma), lan ora ndokokake **Allah**
ing palungguhane Asma. Asma ngadeg kaya anane, ing saben panggonan —
supaya tansah katon ing ngendi Asma iku ana.

## Alef-taw — ⟨את⟩

Ing ukara basa Jawa panjenengan bakal weruh **⟨את⟩** karumat.
Ing basa Ibrani אֵת iku tembung cilik sing nuduhake lesan.
Basa Jawa ora duwe padhanane, lan akeh terjemahan mbuwang tembung
iki tanpa swara. Kita ngejarake katon ing kurung — amarga iku
peranganing wangunan basa. Tinimbang mbusak, kita milih nuduhake
anane.

## Tembung ing ⟨kurung⟩

Kurung ⟨kaya mangkene⟩ nandhani tembung sing **ora ana ing basa
Ibrani** — tembung tambahan sing perlu supaya ukara Jawa bisa
ngadeg. Tinimbang kacampur tanpa tilas, kita ndokokake ing kurung —
supaya tembung Ibrani asli lan tembung tambahan kabutuhaning basa
Jawa tansah bisa dibedakake.

## Asma lan gelar

Tembung Ibrani sing nuduhake Kang Mahasuci — **Elohim**, **El**,
**Shadday**, **Adonay**, **Yah** — katulis miturut swarane.
Ora dipeksa dadi tembung siji kabeh; saben tembung nggawa bobote
dhewe. Jeneng wong lan panggonan uga miturut wujud Ibrani:
Avraham, Yitshak, Yaakov, Moshe, Yerushalayim.

## Tembung sing katengeran

- **khesed** (חֶסֶד) — katresnan setya prajanjian.
  Dudu mung "kawelasan", dudu mung "katresnan".
  Ora ana tembung Jawa siji sing bisa nggawa kabeh.
- **Sheol** (שְׁאוֹל) — papan para wong mati kaya kandhane basa
  Ibrani. Dudu "neraka".
- **nefesh**, **ruakh**, **kavod** — miturut konteks (nyawa utawa
  urip, roh utawa angin, kamulyan utawa bobot) — ora dipaku ing
  tembung siji.

## Saben ayat ing pepadhange dhewe

Saben ayat diterjemahake miturut apa sing diucapake ing panggonane —
kawaca ing kapitayan Ibrani kang mung ana Elohim siji.
Ora nambahi piwulang sing teka mburine, ora maca pungkasaning
crita menyang wiwitane. Tembunge dijarake nggawa tegese ing
panggonane — iku sing dikarepake.

## Wangunan berkas

Saben ayat saben berkas: ayate dhewe, karo tegese saben tembung
kasandhing basa Ibrani — supaya bisa maca saben tembung Ibrani
ing ngarepe tembung Jawane.
